## Dashboard Sections

### Income Overview
- Four stat cards: Total Monthly Income, Needs Budget, Wants Budget, Savings Budget
- **Budget toggle buttons:** Each budget card has a toggle button to switch between monthly and bi-weekly display
- Budget allocation bar showing the visual split of Needs / Wants / Savings
- Percentages update dynamically when allocation is changed in Edit tab

### Income Streams (CRUD)
- Add multiple income streams — each has a name, amount, and a bi-weekly checkbox
- Bi-weekly streams are multiplied × 2 to get monthly income
- Total Monthly Income = sum of all streams' monthly values
- Stream list shows: name, bi-wk chip if applicable, per-pay amount, monthly amount, edit/delete
- Edit via modal; delete with confirmation

### Wants Tracker
- Bi-weekly envelope = (monthly wants budget) / 2
- Donut chart showing spent vs. remaining (turns amber at 80%, red at 100%)
- Purchase list: add by name + amount, delete per item, full period reset
- **Reset Period:** Archives current purchases to `spendingHistory` before clearing, so data is never lost
- Status chip: "On Track" (green) or "Over by $X" (red)
- Enter key navigates from name → amount → add

### Spending Analytics Dashboard
- Collapsible panel inside the Wants Tracker card (toggle button)
- **Filters:** Three filter controls reset when the panel closes
  - **Date Range:** Filter periods by start/end date (YYYY-MM-DD format)
  - **Search by Name:** Filter purchases by partial name match (case-insensitive, live typing)
  - **Reset button:** Clear all filters and show full unfiltered data
  - Active filters shown as "ℹ Filters Active" indicator in summary stats
- **Summary stats (calculated from filtered data):**
  - Periods Tracked: count of periods matching filters
  - Filtered Total: sum of spending in filtered periods
  - Avg / Period: average per period in filtered data
  - Largest Purchase: largest single purchase in filtered results
- **Line chart:** Total spending per filtered period (Chart.js line)
- **Horizontal bar chart:** Top 10 spending categories from filtered periods (Chart.js bar, indexAxis: 'y')
- **Period History:** Full list of periods matching filters, most recent first
  - Each period shows: label, date, total, and all individual purchases matching search filter
  - Per-purchase: Edit (opens modal to change name/amount) and Delete
  - Delete entire period with confirmation (recalculates period total on edit)

### Monthly Expenses
- **Fully dynamic payment cards** — no default cards; user adds their own
- Each card has: label, item list with add form (name, amount, bi-weekly checkbox), card total
- Add payment card via "+ Add Payment Card" button (opens modal for label)
- Rename or delete any card via ✎ / × buttons on the card header
- Bi-weekly items are flagged with a "bi-wk ×2" badge and their monthly amount is doubled
- Summary cards show grand total and Needs budget remaining (turns red if over)

### Loans
- Progress bar per loan showing remaining/original balance
- Colour: red >70% remaining, amber >40%, teal otherwise
- Full CRUD: Add Loan button, Edit and Delete per loan

### Credit Card Utilization
- Bar per card with 30% threshold marker (amber line)
- Chip shows % utilization — green if under 30%, red if over
- Total utilization chip + balance summary
- Bar chart comparing Balance vs. Limit for all cards
- Full CRUD: Add Card button, Edit and Delete per card

### Savings
- Monthly savings target auto-calculated from income × savings%
- Per-account allocation list with: name, monthly amount, edit, delete
- Progress bar: total allocated vs. savings target
- Available balance edited in Edit Values tab

### Subscription Renewals
- Sorted by date ascending
- Day countdown chip: green (>60 days), amber (<60 days), red (expired)
- Full CRUD: inline add form (name + date picker), edit modal, delete

### Wishlist
- Item cards: emoji icon + name + optional clickable URL
- Full CRUD: inline add form (icon, name, URL), edit modal, delete

## CSV Export / Import

### Export (`exportCsv()`)
- Export button (⬇ Export) in the header triggers a download
- File name: `penny-export-YYYY-MM-DD.csv`
- Uses native `Blob` + `URL.createObjectURL()` — no libraries

### Import (`importCsv(event)`)
- Import button (⬆ Import) in the header opens a file picker
- Reads the CSV with `FileReader`, parses it with `parseCsv()`, prompts for confirmation, then replaces all state
- On success: saves to localStorage, calls `renderAll()`, switches to dashboard tab

### CSV Format
The file uses a section-based structure. Each section begins with `SECTION:<name>`, followed by a header row, then data rows. Sections are separated by blank lines.

SECTION:incomeStreams

SECTION:expenseCards

## Key Formulas

```
Monthly income     = sum of all incomeStreams (biweekly ? amount × 2 : amount)
Needs budget       = income × (allocation.needs / 100)
Wants budget       = income × (allocation.wants / 100)
Savings budget     = income × (allocation.savings / 100)
Bi-weekly wants    = wants budget / 2
Monthly expense    = biweekly ? amount × 2 : amount
Grand total        = sum of all expenseCards[].items[] monthly amounts
Needs remaining    = needs budget − grand total
CC utilization %   = balance / limit × 100
Savings unalloc    = savings budget − sum(savingsAccounts[].allocated)
```

## Modal System

The app uses a single reusable modal (`#modal-overlay`). Triggered via:

```js
openModal(title, bodyHTML, onSaveCallback)
closeModal()
```

`bodyHTML` is a string of `.modal-field` divs generated by the `mField()` helper. Clicking outside the modal or pressing Cancel closes it.
